**Search directly:**
- https://pixabay.com/music/search/medieval%20tavern/
- https://pixabay.com/music/search/medieval%20game/
- https://mixkit.co/free-sound-effects/

**Requirements:**
- All tracks must loop seamlessly
- Gentle/cozy — not epic battle music
- Lute/harp/soft percussion primary
- No vocals

## File Format
- SFX: MP3 or OGG (small files, <100KB each)
- Music: MP3 (compressed, <2MB for loop)
- Save to: `public/audio/sfx/` and `public/audio/music/`
