# Background Music — Download Manually

Pixabay and Incompetech require browser download. Pick ONE of these:

## Recommended Tracks (search on pixabay.com/music/):

1. **"Medieval Tavern"** by Migfus20 — cozy lute, perfect loop
   Search: https://pixabay.com/music/search/medieval%20tavern/

2. **"Medieval Lute"** by Alex-Productions — gentle, game-friendly
   Search: https://pixabay.com/music/search/medieval%20lute/

3. **"Tavern Loop"** — search "tavern loop" on pixabay.com/music

## How to add:
1. Download the MP3 from Pixabay (free, no account needed)
2. Rename to `tavern-loop.mp3`
3. Drop it in this folder (`public/audio/music/`)
4. The game will auto-detect and play it
